# V4.2.1 — Exchange Data Licensing and Crosscheck Runbook

## Connected vs pending
SEBI RHP/DRHP official filing index is connected through V4.2. Official filing existence does NOT validate any issue terms.

NSE and BSE market price, subscription, application, listing and lot-size feeds are NOT connected until an appropriate data agreement allows this website's commercial display, processing and publication. An ordinary NSE browser page is not a licensed API.

NSE's Terms prohibit systematic or automated scraping:
https://www.nseindia.com/static/nse-terms-of-use
NSE's market-data sharing policy requires rights aligned with the subscriber agreement:
https://www.nseindia.com/static/market-data/nse-data-policy
Market data subscription contact:
https://www.nseindia.com/static/nse-data-and-analytics/contact-us

## Controlled activation
1. Obtain actual written rights for intended exchange data, commercial publication, reconciliation, user groups and frequency. Keep contracts and API tokens in private storage, not GitHub.
2. Have an authorized reviewer place only a public-safe opaque permission reference, provider ID, permitted exchange(s), expiry, and explicit publication/reconciliation flags in data/approved-exchange-providers.json. Never invent permission.
3. Ingest only rights-cleared normalized records in data/approved-exchange-snapshots.json. Do not harvest exchange websites or reverse-engineer internal endpoints.
4. A record must contain the exact issuer legal name, optional ISIN, timestamp, official NSE/BSE reference URL, provider and evidence scope.
5. Two independently licensed provider IDs covering distinct exchanges must agree exactly PER FIELD. Otherwise show single-source or conflict; never promote values as verified. Observations older than 48 hours are rejected.
6. Build the field audit using: node scripts/v421-ipo-verify.cjs --output=.reports/v421-ipo-audit.json
7. Review conflict reports and original source documents before publication. The independent SEBI index can confirm existence of a filing, not IPO pricing, lot sizes, subscription times or listing performance.

## Input contract
Provider allowlist file: data/approved-exchange-providers.json
Required provider keys: providerId, permissionReference, approved=true, publicDisplay=true, reconciliation=true, allowedExchanges array, expiresAt.

Snapshot file: data/approved-exchange-snapshots.json
Required record keys: exchange (NSE/BSE), issuer, optional ISIN, sourceUrl (official exchange hostname), observedAt (timezone-qualified ISO time), rights providerId and permissionReference, terms.
Supported terms: low, high, lot, open, close, subscriptionTimes, listingPrice.

Illustrations are kept in test code only. Production provider allowlist and snapshots intentionally contain zero records as of the first V4.2.1 commit.

## Governance
The approval registry is a technical editorial safeguard, NOT a legal license. No credentials or confidential agreements should be committed publicly. Before any exchange data are populated, confirm the contract really permits these uses and outputs. NSE/BSE may impose additional restrictions and display requirements.
